First public release of the read-only Figma REST CLI.

- Inspect original components, mixed typography, layout, and geometry.
- Retrieve raw API JSON and export PNG/SVG assets.
- Parse Figma URLs and node IDs offline.
- Use personal access tokens or existing OAuth access tokens.

Download the archive for your operating system and architecture from the assets
below. Extract it and run `figma-cli version` (`.\figma-cli.exe version` in
PowerShell). No Go installation, source checkout, Figma Desktop, or plugin is
required. Network commands require a Figma token with `file_content:read` access.

| System | Architecture | Asset |
| --- | --- | --- |
| macOS | Intel | `figma-cli_0.0.1_darwin_amd64.tar.gz` |
| macOS | Apple Silicon | `figma-cli_0.0.1_darwin_arm64.tar.gz` |
| Linux | x86-64 | `figma-cli_0.0.1_linux_amd64.tar.gz` |
| Linux | ARM64 | `figma-cli_0.0.1_linux_arm64.tar.gz` |
| Windows | x86-64 | `figma-cli_0.0.1_windows_amd64.zip` |
| Windows | ARM64 | `figma-cli_0.0.1_windows_arm64.zip` |

Each archive contains the CLI executable and README. SHA-256 hashes are provided
in `checksums.txt`. See the
[installation instructions](https://github.com/JE-DOG/figma-cli#install-a-prebuilt-binary)
for details.
